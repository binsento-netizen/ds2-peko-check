Peko-Check Lv1Death Stranding 2 save progress: orders and fabrication unlocks. Your save is decoded in this browser and never uploaded.

How to read this. Status comes from the save's mission records: Done = order state Completed, In progress = accepted, Available = listed at a terminal, Locked = not yet offered. Order numbers and names come from the game's own mission lists. Compare with… shows what changed between two saves (earlier play time = before): orders, unlocks, new route segments and, for research, every data section whose bytes differ, plus a text report to paste into the chat.
Orders (numbers, names, clients, destinations, cargo) and unlocks (names, categories, what unlocks them) come from the game's own data, read from a local installation with ShadelessFox's Odradek; every English name is the game's own text. Guide links: Game8's walkthrough for main orders 1-48, Game8's prepper page where Game8 has one, otherwise the Death Stranding Fandom wiki.
